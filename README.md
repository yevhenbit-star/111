# Fisher781 v0.2

Кастомный мод автоматизации для Schedule I + MelonLoader (IL2CPP).

## Что есть

- одно зелёное меню Fisher781;
- открытие/закрытие: **Right Shift**;
- автопосадка;
- автоподготовка горшков;
- автополив;
- автосбор;
- автоупаковка;
- автозакупка через обычный магазин;
- автопринятие появившихся предложений;
- сбор уже заработанных денег у дилеров;
- снабжение дилеров товаром из инвентаря.

Нет бессмертия, бесконечных денег, телепорта, мгновенного роста или спавна бесплатного товара.

## Как собрать через GitHub

1. Открой свой репозиторий `yevhenbit-star/fisher781`.
2. Загрузи **содержимое этой папки**, сохранив папку `.github/workflows/`.
3. Сделай commit в ветку `main`.
4. Открой вкладку **Actions**.
5. Выбери **Build Fisher781 DLL**.
6. Дождись зелёной галочки.
7. Внизу страницы запуска скачай artifact **Fisher781-DLL**.
8. Внутри будет `Fisher781.dll`.
9. Положи DLL в `Schedule I/Mods/`.
10. Запусти игру и нажми **Right Shift**.

## Если Actions красный

Открой неудачный запуск -> `build` -> красный шаг -> скопируй текст ошибки в ChatGPT.

## Примечание

Workflow использует reference DLL только для компиляции. Они не попадают в итоговый `Fisher781.dll`.
